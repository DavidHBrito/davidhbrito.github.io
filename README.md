# The Tomato Timer
The Tomato Timer was made on Feburary, 27, 2026 as a personal project for an IT class.
I made this because I would start a pomodoro timer on pomofocus.io, but I would end up pausing the timer and procrastating. So taking some queues from neal.fun I decided to make a pomodoro timer that is annoying to pause. This was moslty made for me but feel free to use it as well if you like the idea.
This project was abandoned due to being to ambitious.
